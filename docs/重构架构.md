# 股票策略研究平台重构架构

## 模块边界

```text
前端工作台
  ├─ K线与指标
  ├─ 单股 / 多标的 / 多策略回测
  ├─ AI 策略 DSL
  ├─ 全市场任务与策略雷达
  └─ 回测记录与个股明细
          │
FastAPI 接口层
  ├─ 行情接口
  ├─ 回测与记录接口
  ├─ 异步任务接口
  └─ AI 策略双向转换接口
          │
领域服务
  ├─ 行情仓库与前复权数据同步
  ├─ 指标计算（唯一口径）
  ├─ 内置策略引擎
  ├─ 受限 DSL 策略引擎
  └─ 全市场回测 / 扫描任务
          │
SQLite 数据库
  ├─ instruments
  ├─ daily_bars
  ├─ backtest_runs / backtest_results
  ├─ jobs
  └─ scan_signals
```

## 数据口径

- 默认日期：2020-01-01 至当前日期。
- 周期：日线。
- OHLC：前复权。
- 沪深京 A 股运行时日线统一使用 AKShare：首选 `stock_zh_a_hist`，失败时回退 `stock_zh_a_daily`；本地 A 股历史库只读取 AKShare 来源，隔离遗留腾讯、东财和 Yahoo 行。港股与美股暂保留东方财富兼容路径。KDJ 由本地按 KDJ(9,3,3) 计算，使用回测开始日前最多 250 根日线预热，预热行不进入回测区间。
- 信号：T 日收盘生成。
- 成交：T+1 日前复权开盘价，买卖分别扣单边手续费。
- 行情以 `symbol + trade_date` 为唯一键，重复同步会更新而不会增加重复 K 线。
- 首次全市场同步使用当前 A 股股票池，因此历史横截面存在幸存者偏差；严谨研究还需补充历史上市、退市及每日可交易股票池。

## 全市场任务

全市场同步、回测和扫描均为持久化异步任务。创建任务后立即返回 `job_id`，客户端轮询任务状态：

```text
pending → running → completed / failed
```

建议执行顺序：

1. 同步全市场行情。
2. 执行全市场策略回测。
3. 每个交易日数据更新后执行策略雷达。

同步任务支持两种模式：首次建库或修复数据时使用 `full`，按所选日期范围重新拉取；日常更新使用 `incremental`，系统读取每只股票最后交易日，仅覆盖最近 10 个自然日并补充之后的新数据。该回看窗口用于处理近期前复权变化，同时避免每天重复下载 2020 年以来全部行情。

回测工作台同时支持个股即时回测和全市场异步回测。全市场模式使用本地数据库中的全部当前 A 股股票，个股 K 线、B/S 和资产曲线也可以从全市场记录下钻查看。股票列表通过 AKShare `stock_info_a_code_name` 获取，并用 `universe_member` 区分股票池成员与曾单独查询过的 ETF。2026-08-11 实际读取股票列表为 5542 只；具体数量会随上市、退市及 AKShare 上游口径变化。

回测结果支持按股票代码或名称模糊查询、按策略过滤，并可按收益、最大回撤、夏普、胜率或股票代码排序，采用服务端分页读取。记录汇总会持久化平均收益等统计指标，因此重新打开页面后仍可直接查看收益信息。

回测记录支持软删除。删除操作只写入 `backtest_runs.deleted_at`，记录会从列表、详情、分页结果和单项结果接口中隐藏，关联的压缩曲线及交易明细暂不物理清除，便于后续增加回收站或恢复功能。

用户可同时勾选 2～10 条未删除记录进行 PK。服务端按“记录 × 策略”聚合并按平均收益降序排名；每一行同时给出样本数、平均基准收益、平均超额收益、平均最大回撤、平均夏普、平均胜率、盈利标的比例和跑赢基准比例。盈利标的比例是策略收益大于 0 的样本占比，跑赢比例是策略收益高于同标的买入持有基准的样本占比。

“今日开仓”以数据库中不晚于指定结束日期的全市场最近交易日为准，只显示该交易日收盘新产生的 B 信号。

## AI 策略安全边界

AI 不生成或执行任意 Python。它只能输出由 `NAME`、`ENTRY`、`EXIT` 组成的受限 DSL。解析器使用 Python AST 做白名单校验，禁止：

- import
- 属性访问
- 下标访问
- 循环和函数定义
- 文件、网络、系统命令
- 白名单外的函数

支持价格序列、MA、MACD、RSI、KDJ、ATR、BOLL、REF、上穿/下穿以及组合逻辑。DSL 可以直接进入回测引擎，也可以反向生成策略说明。

## 规模说明

SQLite 适合当前单机 Demo。全市场回测的资产曲线与成交事件使用 zlib 压缩保存，记录列表只读取指标摘要，点击个股时再读取完整曲线。若升级为多人并发、分钟线或分布式回测，应将 SQLite 替换为 PostgreSQL/TimescaleDB，并将进程内异步任务替换为 Celery、RQ 或独立任务服务。
