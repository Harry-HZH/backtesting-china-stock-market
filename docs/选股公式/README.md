# 条件选股公式

目录内提供同花顺、通达信的 MA120/MA200 回踩确认公式，以及同花顺 RSI 反转 ATR 风控策略的入场选股公式。

## RSI反转+止盈止损（同花顺）

文件：`同花顺-RSI反转ATR风控.txt`

选股条件与项目当前回测入场逻辑一致：

1. 使用同花顺日线 RSI(14)：`SMA(MAX(C-LC,0),14,1) / SMA(ABS(C-LC),14,1) × 100`。项目指标展示和回测均使用相同递推口径，并读取回测开始日前的历史日线预热。
2. 前一交易日 RSI 不高于 30，当日 RSI 向上穿越 30。
3. 当日收盘价高于开盘价，即当日收阳。
4. 当日收盘价至少高于最近20日最低价2%，排除仍贴近阶段新低的弱反抽。
5. 当日收盘后产生选股信号，项目在下一交易日开盘买入。

普通条件选股公式只负责发现入场信号，不能可靠维护完整持仓状态。项目中的下列规则不能仅靠一个无状态 `XG` 公式精确复现：

- 实际下一日开盘成交价；
- 初始止损为 `1.5×ATR(14)`，并限制在买入价的 4%～5%；
- 盈利达到 8% 后启用 `2×ATR(14)` 跟踪止盈，回撤距离限制在 4%～6%；
- 持仓最高收盘价、20日时间退出以及止损后的5日冷静期。

这些退出规则应在同花顺预警/交易系统中按实际持仓价维护，或继续由本项目回测执行。不要把选股公式当天的收盘价直接当成下一日开盘成交价。

## MA120 / MA200 信号口径

以选股当天为第 5 天：

1. 第 1 天（即选股日前 4 个交易日）之前，收盘价位于对应均线上方。
2. 第 1 天最低价触及或跌破均线，收盘价允许跌破均线。
3. 从第 1 天到第 5 天，对应均线每天严格高于前一天。
4. 第 2～5 天每天最高价严格高于当天的动态均线。
5. 第 5 天收盘价严格高于当天的动态均线，收盘后出现选股信号。
6. MA200 版本额外要求第 1～5 天每天都满足 MA200>MA250。
7. 与项目回测口径一致时，在下一交易日开盘执行买入。

公式没有使用未来函数。`REF(...,4)` 表示第 1 天，`REF(...,3)` 至当天依次表示第 2～5 天。

## 使用方法

### 同花顺

进入“公式管理 → 条件选股公式 → 新建”，选择日线周期，将对应同花顺公式全文粘贴并测试通过后执行选股。

### 通达信

进入“公式管理器 → 条件选股公式 → 其他类型 → 新建”，选择日线周期，将对应通达信公式全文粘贴并测试通过后执行选股。

## 数据设置

- 周期使用日线。
- K 线复权方式使用前复权，与项目回测口径保持一致。
- MA120 至少需要 125 个交易日数据；MA200 版本包含 MA250 过滤，至少需要 255 个交易日数据。实盘建议下载完整日线数据后再选股。
- 选股结果只代表技术条件成立，不处理停牌、一字涨跌停、成交量不足以及下一日无法按开盘价成交等情况。
