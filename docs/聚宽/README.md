# 聚宽策略代码

`RSI反转止盈止损.py` 对应系统当前的“RSI反转+止盈止损”单股票策略。

使用前修改 `g.security`：

- 上海股票：`600519.XSHG`
- 深圳股票：`000001.XSHE`
- 沪深300基准：`000300.XSHG`

代码通过 `set_option("use_real_price", True)` 开启聚宽动态复权，并通过
`attribute_history(..., include_now=False, fq="pre")`（`include_now=False` 为默认行为）
读取截至上一交易日的日线。因此每天开盘运行时，执行的是上一交易日收盘确认的信号。

当前版本是单股票、满仓策略，没有加入独立的基本面评分开关，也不设置止损后的冷静期。手续费按本地回测的双边万分之三设置，未计印花税、最低佣金和滑点；如需贴近真实交易，应自行修改 `OrderCost` 和 `FixedSlippage`。

`RSI全市场组合回测.py` 是当前共享资金池版本：初始资金1000万元，总仓位上限100%、单票上限1%、最多100只、单日全市场原始RSI信号至少350个、次日开盘高开不超过5%、单边基础滑点5bps。没有股票机会时保留现金，不再使用红利ETF现金管理。原始信号数量按每天全市场独立扫描计算，不受已有持仓、可用资金和空位影响；未达到门槛时仍正常执行卖出，但不新增股票持仓。候选超过空位时，按“离20日低点反弹幅度 + RSI/20”从低到高选择，且不使用止损后的冷静期。候选不足时保留现金，不突破1%的单票上限。

当前聚宽文件默认按 RSI14 统计全市场信号，资金池默认总仓位100%、单票1%、最多100只、信号门槛350。`initialize()` 中的 `g.market_signal_threshold` 可手动修改为任意数量（设为0关闭）；`g.rsi_period` 可手动修改为其他周期进行对照。

开仓与成交参数集中在 `initialize()`：`g.market_signal_threshold`、`g.max_opening_gap_pct`、`g.base_slippage_bps`、`g.minimum_average_turnover`、`g.volume_ratio_threshold`、`g.require_above_ma200`、`g.require_ma200_rising` 和 `g.exclude_st`。其中成交额填人民币金额，例如5000万元写为 `50_000_000`；量能比为信号日前5日均量/更早30日均量；数值门槛填0表示关闭。当前默认关闭成交额、量能比和MA200过滤，并保留ST股票；聚宽使用 `PriceRelatedSlippage` 对买卖两侧分别施加5bps滑点。

回测结束后的聚宽收益图除平台原生策略/基准曲线外，还会通过 `record()` 展示“策略累计收益”“沪深300累计收益”和“资金使用率”。前两条统一以百分比表示，并从回测首个交易日基准归零，方便直接观察超额收益来自哪一段行情。

全市场版本采用增量RSI：回测首日为每只股票读取250根日线预热同花顺RSI，之后把 `average_gain`、`average_change`、上一日RSI和收盘价保存在 `g.rsi_states`，每天只读取最新1根收盘价递推更新。新上市或首次进入股票池的股票单独预热一次，避免每天对全市场重复计算250日历史。
